# Deployment Guide

This guide covers deployment procedures for both the **Static Site Generator** (Track 1) and the **WordPress Theme** (Track 2).

---

## 1. Static Site Deployment (Track 1)

### 1.1 Automated Deployment via GitHub Pages

The repository includes a production-ready GitHub Actions workflow in `.github/workflows/deploy.yml`.

#### Workflow Highlights:
- **Triggers**: Automatic deployment on push to the `main` branch; manual trigger via `workflow_dispatch`.
- **Node Environment**: Executes on `ubuntu-latest` with Node.js 22.
- **Image Optimization**: Preinstalls the `webp` package (`cwebp`) for generating responsive image variants (`640w`, `1024w`, `1600w`).
- **Environment Context**:
  - `SITE_URL`: Set dynamically to `https://${{ github.repository_owner }}.github.io`.
  - `BASE_PATH`: Set dynamically to `/${{ github.event.repository.name }}`.
- **Artifact Pipeline**: Uses `actions/upload-pages-artifact@v5` and `actions/deploy-pages@v5`.

#### Enabling GitHub Pages in Repository Settings:
1. Navigate to **Settings → Pages** in your GitHub repository.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Push changes to the `main` branch or trigger the workflow manually under **Actions → Deploy to GitHub Pages → Run workflow**.
4. The deployed URL will be displayed in the Actions deployment output (e.g., `https://medhatse.github.io/Vision-Studio/`).

#### Custom Domain on GitHub Pages:
If using a custom domain (e.g. `studios.example.com`):
1. In repository settings under **Settings → Pages → Custom domain**, enter your domain.
2. Ensure DNS records point to GitHub's IP addresses (`185.199.108.153`, etc.) or CNAME record.
3. In your build step, pass `CNAME_DOMAIN=studios.example.com` to emit a `dist/CNAME` file.

### 1.2 Deployment to Netlify

Netlify natively supports the `_redirects` file generated by `scripts/build.mjs`:

1. Connect your repository to Netlify.
2. Configure build settings:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
3. Add Environment Variables:
   - `SITE_URL`: `https://your-site.netlify.app` (or custom domain)
   - `BASE_PATH`: Leave empty for root domain
4. Legacy URL redirects (`/london-studio-1/` → `/studios/london-studio-1/`, etc.) will be automatically handled with HTTP 301 status via `dist/_redirects`.

---

### 1.3 Deployment to Cloudflare Pages

1. In the Cloudflare dashboard, go to **Workers & Pages → Create application → Pages**.
2. Connect the `Vision-Studio` repository.
3. Configure build parameters:
   - **Framework preset**: `None`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
   - **Environment variables**: `SITE_URL = https://your-domain.com`

### 1.4 Self-Hosted Nginx / Apache Server

To host the static build on an independent Linux server:

#### Build the Artifact:
```bash
SITE_URL=https://vision-studios.net npm run build
```

#### Example Nginx Configuration (`/etc/nginx/sites-available/vision-studios.conf`):
```nginx
server {
    listen 80;
    listen [::]:80;
    server_name vision-studios.net www.vision-studios.net;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    listen [::]:443 ssl http2;
    server_name vision-studios.net www.vision-studios.net;

    root /var/www/vision-studios/dist;
    index index.html;

    ssl_certificate /etc/letsencrypt/live/vision-studios.net/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/vision-studios.net/privkey.pem;

    # Static compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript image/svg+xml;

    # Cache headers for immutable static assets
    location /static/ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
    }

    # Clean URL handling and 404 fallback
    location / {
        try_files $uri $uri/ $uri/index.html /404.html;
    }

    error_page 404 /404.html;
}
```

## 2. WordPress Theme Production Deployment (Track 2)

This workflow describes installing `vision-studios-theme` onto the live WordPress installation at `vision-studios.net`.

### 2.1 Pre-Deployment Safety & Backup
Before initiating theme activation on a production WordPress site:
1. **Full Database Backup**: Create a snapshot using WP-CLI or phpMyAdmin:
   ```bash
   wp db export backup-pre-theme-activation-$(date +%Y%m%d).sql
   ```
2. **File Backup**: Backup `wp-content/themes` and `wp-content/uploads`.
3. Keep the current active theme installed as a fallback.

### 2.2 Build the Distribution Zip
On your local machine or build agent:
```bash
npm run theme:zip
```
This compiles Tailwind CSS (`assets/app.css`), minifies JavaScript and post-production CSS, compiles JSON data imports (`import.json` and `tr.json`), and creates `wordpress/vision-studios-theme.zip`.

### 2.3 Theme Upload & Activation
1. Log into WordPress Admin (`/wp-admin`).
2. Go to **Appearance → Themes → Add New → Upload Theme**.
3. Select `wordpress/vision-studios-theme.zip` and click **Install Now**.
4. Click **Activate**.

### 2.4 Flush Rewrite Rules
Navigate to **Settings → Permalinks** and click **Save Changes**. This registers rewrite rules for:
- `/studios/<slug>/`
- `/city/<slug>/`
- `/tr/city/istanbul/` and `/tr/studios/<slug>/`

### 2.5 Run the Content Importer
1. Navigate to **Studios → Import Content** in the WP admin sidebar.
2. **Important**: Leave *"Also import news posts"* unchecked on a live site where posts already exist to avoid creating duplicate entries.
3. Click **Run import**.
   - The importer creates 14 studios, 4 cities, services, clients, and core pages.
   - It matches existing image URLs in the media library so zero duplicate files are uploaded.
   - Older Elementor pages are set to draft status so their legacy URLs redirect to the new structure.

### 2.6 Configure Rank Math SEO
If Rank Math is installed:
1. **Rank Math → Titles & Meta → Studios**: Set Title template to:
   `%title% — TV Studio Hire in %primary_taxonomy_terms% %sep% %sitename%`
2. **Rank Math → Titles & Meta → Cities**: Set Title template to:
   `%term% TV & Production Studios for Hire %sep% %sitename%`
3. **Rank Math → Sitemap Settings**: Include `Studios` and `Cities`; exclude `Services` and `Clients`.
4. Resubmit `sitemap_index.xml` in Google Search Console.

### 2.7 Verification & Rollback Plan
- **Verification**: Run `npm run seo:audit -- https://vision-studios.net` to confirm status codes, canonicals, and metadata.
- **Rollback**: If an issue occurs, re-activate the previous theme under **Appearance → Themes** and republish drafted pages in **Pages → Drafts**.
